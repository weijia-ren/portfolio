Statistical Foundations

Statistics estimates unknown quantities, quantifies uncertainty, distinguishes signal from noise, and supports decisions when truth is not directly observed.

Start with the estimand
QUESTION
What do we want?
→
ESTIMAND
What quantity?
→
ANALYSIS
What evidence?

Question → Estimand → Analysis

Common estimands

Population mean · proportion · mean difference · treatment effect · correlation · regression coefficient · odds ratio

Why first?

A test or model is useful only when it targets the quantity the question actually asks about.

Core principle

Do not start with “Which test?” Start with “What quantity am I estimating?”

Confidence vs credible interval

Both express uncertainty, but probability attaches to different objects.

Confidence interval
Estimate ± Critical Value × SE

A 95% procedure captures the true parameter in about 95% of repeated samples.

Avoid

Not: “There is a 95% probability this specific interval contains the fixed parameter.”

Credible interval

Given the model, prior, and observed data, the parameter has 95% posterior probability of lying inside the interval.

Memory hook

CI = Long-run Coverage
CrI = Posterior Probability

Null & alternative hypotheses

Hypothesis tests compare observed evidence with a specified null model.

Null hypothesis
H₀: μA − μB = 0

Usually encodes no difference or no effect at a specified null value.

Alternative
HA: μA − μB ≠ 0
Decision language

Reject H₀

or

Fail to reject H₀

Important nuance

We do not literally prove or “accept” the null hypothesis.

Type I & Type II error

Testing decisions can create false alarms or missed detections.

Type I · α
P(Reject H₀ | H₀ true) = α

False alarm

Type II · β
P(Fail to reject H₀ | HA) = β

Missed signal

Significance level

α is the pre-specified Type I error threshold. .05 is common—but convention, not law.

Decision trade-off

Lowering α reduces false alarms but can increase missed detections unless sample size or signal increases.

Memory hook

Type I = false alarm.
Type II = missed signal.

The p-value

A p-value is a probability about data under the null—not a probability that the null is true.

Definition

Assuming the null hypothesis and statistical model are true, the probability of a result at least as extreme as observed.

p = P(Data this extreme or more | H₀)
Example · p = .03

If the null model were true, results at least this extreme would occur about 3% of the time under repeated sampling.

Not this

× P(H₀ | Data)
× “probability the result occurred by chance”

Memory hook

p = P(Data | H₀)
not P(H₀ | Data)

Sample size & p-values

Large samples increase sensitivity to small departures from the null.

What large n does

Makes small effects detectable.

It does not make those effects important.

What to inspect
Effect Size + CI + Decision Threshold

not only p < .05

Interpretation

Statistical detectability and practical importance become increasingly distinct as precision grows.

Memory hook

Large n makes small effects detectable—not important.

Effect size & practical significance

Evidence, magnitude, and decision relevance are different questions.

Examples
Mean difference: X̄T−X̄C
Standardized d = (X̄T−X̄C)/s
Risk difference: P(Y=1|T)−P(Y=1|C)
Correlation: r
Decision lens

Compare the estimated effect and CI with the minimum practically meaningful effect.

Decision ingredients
Magnitude + Uncertainty + Cost + Risk + Guardrails
Memory hook

Significance = evidence.
Effect size = magnitude.
Practical significance = decision relevance.

Power

Power is the probability of detecting a specified alternative under a specified design.

Definition
Power = 1 − β

Probability of rejecting H₀ when the assumed alternative effect is truly present.

Power rises when

n ↑
Effect size ↑
Noise ↓
α ↑

Direction

A justified one-sided test can have greater power in its specified direction than a two-sided test.

80% convention

80% is common—not universal. Required power depends on missed-effect consequences, collection cost, decision importance, and design.

Memory hook

Power is conditional on the assumed effect and study design.

Sample size & MDE

Plan around the inferential or decision objective—not around the sample already available.

Estimation goal

Confidence level · margin of error · outcome variability · expected proportion

Testing goal

Alpha · desired power · effect size / MDE · variance / base rate · allocation · design

Minimum Detectable Effect

Smallest effect the planned study has adequate power to detect.

Key principle

Choose the meaningful effect first, then determine the sample needed—not the other way around.

One-sided vs two-sided tests

Direction is part of the design and scientific question.

Two-sided
HA: θ ≠ 0

Use when meaningful outcomes could occur in either direction.

One-sided
HA: θ > 0   or   θ < 0

Use only when one direction is scientifically or decision-relevant.

Timing rule

Choose before seeing results.

Do not switch because the two-sided p-value nearly reached .05.

Memory hook

Direction is a design choice—not a rescue strategy.

Multiple testing

Testing many hypotheses increases the opportunity for false discoveries.

Where it appears

Many metrics · outcomes · subgroups · feature comparisons

Bonferroni
α* = α / m

Strong family-wise error control; can be conservative.

Holm

Sequential FWER correction

Often preferable to simple Bonferroni when applicable.

Benjamini–Hochberg
p(i) ≤ (i/m)q

Controls false discovery rate; useful for larger exploratory programs.

Key principle

Confirmatory → stronger FWER control.
Exploratory → FDR may fit.

T-test vs Z-test

The “use Z when n ≥ 30” shortcut is not a reliable rule.

Z framework

Classically used when the relevant population variance is known, or when a justified asymptotic procedure uses a normal reference distribution.

T framework

Used when population variance is estimated from the sample—the common case for mean comparisons.

Convergence
df ↑ ⇒ t → Normal

The practical difference shrinks as degrees of freedom increase.

Interview rule

If population variance is unknown, use the t framework rather than switching automatically to Z at n=30.

Left skew

Usefulness of mean · small-sample SEs · sensitivity to extremes · model choice

Boundary

A skewed raw variable does not automatically invalidate regression or require a nonparametric test.

Mean vs median

The right summary depends on the quantity relevant to the decision.

Mean

Uses every observation.

Sensitive to extreme values; useful for aggregate burden or totals per unit.

Median

Middle observation.

More resistant to extremes; useful for a typical experience.

Response-time example

Median: typical experience
Mean: aggregate burden
Tail percentile: worst experiences

Memory hook

Summary statistic follows the decision.

Correlation

Association is not identification of a causal pathway.

Range
−1 ≤ r ≤ 1

Strength and direction of association on a specified scale.

Causal boundary
Correlation ≠ Causation

Association can reflect causality, reverse causality, confounding, selection, or chance.

Pearson

Linear association

Spearman

Rank-based monotonic association

Useful for monotonic nonlinear patterns or substantively meaningful ranks.

Correction

Do not choose Spearman only because a variable looks non-normal.

Missing data

Mechanism matters more than an arbitrary percentage threshold.

Mechanisms
TypeMeaning
MCARMissingness unrelated to observed or unobserved values
MARExplained by observed information
MNARStill depends on unobserved values after conditioning
Possible approaches

Complete case · weighting · multiple imputation · model-based methods · sensitivity analysis

Multiple imputation

Creates plausible completed datasets, analyzes each, and combines estimates while preserving uncertainty.

Avoid universal rules

There is no valid “delete below 30%, impute above 30%” rule.

Important corrections

Mean/median replacement can understate uncertainty and distort relationships. A missing category may help prediction but does not solve the mechanism.

Memory hook

Missingness mechanism matters more than missingness percentage.

Outliers & influential observations

An unusual observation may be wrong, rare-but-real, or influential—those are different issues.

Ask first

Wrong? Rare-but-real? Influential?

Diagnostics

Boxplots · scatterplots · standardized residuals · leverage · Cook’s distance

Not VIF

VIF evaluates multicollinearity—not outliers.

Investigate

Data quality · substantive plausibility · influence on conclusions

Rule

Do not automatically delete extreme values.

Multicollinearity: know the idea

Overlapping predictor information hurts separation of effects more than overall prediction.

Consequences

Unstable coefficients · larger SEs · sign changes · difficulty separating effects

Diagnostic
VIFj = 1 / (1−Rj²)

No universal cutoff automatically invalidates a model.

Possible responses

Remove / combine redundancy · redefine by question · regularize for prediction · dimension reduction

Memory hook

Multicollinearity hurts separation of effects more than prediction.

Parametric vs nonparametric

Choose the method based on the estimand, structure, assumptions, and robustness—not a desired p-value.

Parametric

Specified model structure

t-test · ANOVA · linear regression

Rank-based alternatives

Mann–Whitney · Wilcoxon signed-rank · Kruskal–Wallis

Decision questions

What estimand? What dependence? Which assumptions matter? How robust is the conclusion?

Avoid

Do not switch methods because the p-value is “almost significant.”

Key principle

Method choice precedes result inspection.

Frequentist vs Bayesian uncertainty

The frameworks answer uncertainty questions using different probability statements.

Frequentist

Parameters are fixed; repeated-sampling behavior determines uncertainty.

SEs · confidence intervals · p-values

Bayesian
Posterior ∝ Likelihood × Prior
p(θ|Data) ∝ p(Data|θ)p(θ)
Direct probability
P(θ > δ | Data) = .93

δ can represent a meaningful decision threshold.

Interpretation contrast

Frequentist: procedure behavior.
Bayesian: posterior uncertainty given model, prior, and data.

Decisions under uncertainty

Statistical evidence is one input to a product or policy decision.

Decision equation
Effect + Uncertainty + Cost + Risk + Guardrails + Reversibility
Example threshold
Roll out only if Effect > 2

Ask which effects remain plausible and whether they cross the practical threshold.

Not enough

“Is p < .05?”

Statistical significance does not encode costs, risks, or action constraints.

Key principle

Statistical significance thresholds and decision thresholds are different.

Common interview traps → better answers

Replace the shortcut with the correct conditioning statement, uncertainty principle, or diagnostic.

Nine traps
× “p=.03 means a 3% chance the result happened by chance.”
Under the null model, results this extreme or more would occur about 3% of the time.
× “Large samples make p-values meaningless.”
They can make tiny effects detectable, so magnitude and practical importance matter more.
× “Not significant means no effect.”
The estimate may be too uncertain to distinguish from zero.
× “80% power means an 80% chance this study is significant.”
Power is conditional on an assumed true effect and study design.
× “If n≥30, use a Z-test.”
With unknown population variance, the t framework remains appropriate.
× “A 95% CI gives 95% probability the parameter is inside.”
That is a credible-interval interpretation, not the standard frequentist CI interpretation.
× “Delete cases if less than 30% are missing.”
Missingness mechanism matters more than an arbitrary percentage.
× “VIF detects outliers.”
VIF diagnoses multicollinearity; residual, leverage, and influence diagnostics address unusual cases.
× “More data solves statistical problems.”
More data reduces sampling uncertainty but does not automatically fix bias, confounding, measurement error, or design.

30-second interview answer

Lead with the estimand, quantify uncertainty, interpret evidence correctly, and connect the plausible effect range to action.

Ready-to-use answer
“I’d start by defining the estimand rather than jumping straight to a statistical test. I’d report the point estimate together with its uncertainty and focus first on the effect size and confidence interval. If I use a p-value, I’d interpret it as how unusual the observed data are under the null model, not as the probability the null is true. I’d also consider power, multiplicity, missing-data assumptions, and whether the study design supports the inference. Most importantly, I’d compare the plausible effect range with the minimum practically meaningful effect and combine magnitude and uncertainty with costs, risks, and guardrails rather than using statistical significance alone as the decision rule.”
Answer architecture
Estimand
→
Estimate + interval
→
Correct p-value
→
Power + multiplicity
→
Missingness + design
→
Practical decision
Strong closing

Magnitude and uncertainty inform the decision; significance alone does not make it.
